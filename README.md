 ☕ Café Nova — Virtual Café

A little coffee, a little creativity, and a whole lot of code.

Café Nova is a Flask-based virtual café application that brings the café experience online through an interactive menu and personalized drink customization.

 ✨ What Makes It Special
- Explore an interactive café menu.
- Customize beverage sizes.
- Adjust sugar preferences.
- Enjoy a simple ordering experience.

 💻 Built With
Python • Flask • HTML • CSS • JavaScript

 ⚙️ Getting Started

bash
git clone YOUR_REPOSITORY_URL
cd Cafe-Nova
pip install -r requirements.txt
python app.py


Visit http://127.0.0.1:5000 to explore the application.
